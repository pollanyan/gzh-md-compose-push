# 主题效果示例

## 为什么要专门排版

技术文章发到公众号，最费心的往往不是写作，而是把结构、代码和引用整理成能直接粘贴的版式。

**加粗**用来点出重点，`行内代码`保持原样，引用角标 [[1]] 放在右上角。

> 好的排版让读者只关注内容，而不是格式。

### 代码示例

```python
def build_article(title):
    name = "gzh"
    print("ready:", title, name)
```
